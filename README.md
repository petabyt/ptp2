# ptp2

libptp2 extracted from [libgphoto2 upstream](https://github.com/gphoto/libgphoto2/tree/master/camlibs/ptp2). The gphoto2 backend has been
replaced with a compatibility layer over the libpak runtime.

`ptp2_upstream/` is an unmodified copy of camlibs/ptp2 at [this commit](https://github.com/gphoto/libgphoto2/commit/c58e2a19b1113fe139101e592c1e4609a55570a1)
